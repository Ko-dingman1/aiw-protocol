# v0.2 implementation plan

Scope: user selected external API integration and a human-facing dashboard. Preserve the database-free architecture and offline mock demos.

1. Repair any hosted CI failures before declaring the next release complete.
2. Integrate Open-Meteo Seoul current model weather through a validated adapter, with timeout, caching, request coalescing and explicit failure state.
3. Preserve honest source classification: imported model data, not a sensor measurement; no silent mock fallback in live mode. Include attribution.
4. Add a Korean dashboard with real browser discovery, direct node queries, searchable object cards, raw JSON, source/provenance inspection, conflicting claims and derivation references.
5. Add manual refresh and live SSE display with explicit connection and source status. Restrict browser access to the local dashboard origin.
6. Add injectable API tests, dashboard route tests and live network smoke test. Retain offline CI tests.
7. Update English/Korean docs, release notes, build scripts and versions, run full validation, publish and verify hosted CI.

Authentication/provider identity, persistence, schema catalog, history, pagination, federation and SSE replay remain future work. Finance stays mock-only. Preserve the v0.1.0 tag.
