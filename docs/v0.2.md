# v0.2 — live data and Observatory

Run pnpm dev for an offline dashboard, or pnpm dev:live for external Seoul weather. Open http://127.0.0.1:4001. Use pnpm demo:live for a one-shot CLI test. pnpm build copies UI assets so node dist/scripts/dev.js --live also works.

## Compatibility

All workspace versions are 0.2.0 and descriptors advertise protocolVersion 0.2. This prototype validates the version strictly: upgrade registry, node and client together. The Knowledge Object envelope and query/fetch/SSE shapes are unchanged. v0.1.0 remains available as a Git tag. New error: AIW_UPSTREAM_UNAVAILABLE. Live weather ID is weather:seoul:open-meteo; mock weather remains weather:seoul.

## Source semantics

[Open-Meteo documentation](https://open-meteo.com/en/docs) describes current weather as model data. The adapter publishes a record with imported-data origin, source.mock=false, Celsius units and Unix time converted to UTC. observedAt is model valid time; updatedAt is retrieval time. Source and publisher remain separate. [Attribution](https://github.com/open-meteo/open-meteo) appears on the dashboard and CLI. The free hosted endpoint is for non-commercial use; see [pricing and usage](https://open-meteo.com/en/pricing) before commercial deployment.

The fixed Seoul coordinates do not collect the user's location. No API key is required for this demo. Initial load and manual refresh are the only upstream calls; refresh is cached for 60 seconds. Concurrent refreshes share one request. Errors have a cooldown and never switch to mock data. Last successful weather remains visible after a later failure, with an error banner and its timestamp. All state is lost on restart.

## Dashboard

Search subject/property/provider, filter namespaces, compare conflicting values, inspect source/provenance/evidence, follow versioned derivation references, and expand raw JSON. Finance and employee-count examples remain fictional even in live mode. The UI compares unequal values for matching subject/property; it does not decide which claim is true. The reference indicator checks only currently loaded inputs, not truth or authentication.

## Limits

Local loopback use only. No accounts, database, history, schema catalog, pagination, federation, deployment or SSE replay. The dashboard intentionally restricts discovered destinations to its configured local node. External API availability is not guaranteed. Offline tests inject API responses and do not depend on the internet.
