# Roadmap

## v0.1 — implemented prototype

Knowledge envelope and origins, versioned derivations, node descriptor, in-memory registry, resolver, query/fetch, SSE updates, adapters, fictional demos and a synthetic benchmark.

## v0.2 — implemented

Open-Meteo adapter, optional live weather, Korean responsive dashboard, source status and manual refresh, caching/timeouts, browser discovery and SSE, and Windows CI line-ending repair.

## Next reliability work

Domain schema catalog, richer entity identifiers, provider identity, established authentication integration, immutable version history and pagination remain unimplemented.

## v0.3 — proposed

JSON-LD/RDF interoperability experiments, an MCP adapter, and more source adapters with conformance tests.

## Future research

Federation and decentralized discovery; signed Knowledge Objects using standard cryptography; CBOR/Protobuf; HTTP/3 evaluation; dedicated URI scheme research. These require evidence of need and are not implemented. No blockchain, cryptocurrency or consensus system is planned for v0.1.
